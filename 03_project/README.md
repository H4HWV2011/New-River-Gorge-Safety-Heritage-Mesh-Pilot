# Project Materials

This folder contains the core project materials for the **New River Gorge Safety & Heritage Mesh Pilot**, a phased community-connectivity and local-information initiative led by Harmony for Hope, Inc.

The project is designed to begin with a modest, fundable public-access pilot at the Fayette County Community Arts Center in Mount Hope, West Virginia. The proposed pilot would test free public Wi‑Fi, useful local information, heritage interpretation, visitor resources, and community stewardship before any broader expansion is considered.

This folder distinguishes between existing organizational and digital foundations, proposed pilot activities, project timelines, and estimated budget needs. It does not represent that a corridor-wide mesh network, public marketplace, MountainShares payment system, or heritage-node system is currently deployed.

## Current Status

The project is in a planning, partnership-development, and fundraising stage.

Harmony for Hope has assembled organizational records, project documentation, an initial first-year budget, a phased timeline, a signed WV Hive agreement, and letters of support from public, municipal, academic, and community partners.

The following are not represented as already deployed or active public operations:

- A corridor-wide public Wi‑Fi network.
- A fully installed heritage-node network.
- A public marketplace with active listings.
- MountainShares payment or transaction functions.
- A DAO/DUNA independently operating the project.
- Confirmed expansion beyond the first proposed pilot site.

Any future expansion depends on funding, site permissions, partner coordination, technical review, responsible stewardship planning, and demonstrated public benefit.
