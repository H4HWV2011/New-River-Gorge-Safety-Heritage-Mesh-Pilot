# Grant Evidence

This directory contains grant-related evidence, planning records, application materials, correspondence, funding-development documents, and award documentation connected to the New River Gorge Safety & Heritage Mesh Pilot.

The purpose of this directory is to preserve a clear record of how potential funding opportunities are identified, developed, submitted, reviewed, awarded, declined, revised, or carried forward into later project phases.

Grant activity is treated as part of the project's evidence record.

A funding opportunity, draft budget, support letter, application concept, or submitted proposal does **not** by itself establish that a project component is funded, authorized, approved, or operational.

## Evidence Principle

The project distinguishes among:

```text
funding idea
    ↓
grant-development concept
    ↓
application preparation
    ↓
submitted application
    ↓
funder review
    ↓
award / decline / revision
    ↓
accepted award and approved scope
    ↓
implementation
    ↓
closeout and reporting
