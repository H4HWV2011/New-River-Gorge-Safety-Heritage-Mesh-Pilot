# Recordkeeping Rule

Submitted materials should remain the permanent record of what the funder actually received.

Do not silently replace:

* submitted applications;
* budgets;
* attachments;
* submission confirmations;
* or historical supporting materials

with later project revisions.

Instead, preserve later records separately.

# Historical Application vs. Current Project

A submitted application preserves what Harmony for Hope requested at a particular point in time.

It does not automatically define the project's current scope.

Therefore:

```text
submitted September 2026 application
        ≠
current governing project scope
```

and:

```text
submitted application budget
        ≠
current master pilot budget
```

Later changes should be documented in current project and development records rather than retroactively inserted into the historical application.
