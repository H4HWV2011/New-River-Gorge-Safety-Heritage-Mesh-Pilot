# Decision Recording

When a decision is received, do not alter the submitted application.

Instead:

1. preserve the decision record in `follow-up-and-decision/`;
2. update this README's **Current verified status**;
3. record the decision date;
4. record the amount awarded, if applicable;
5. distinguish requested scope from approved scope;
6. preserve any revised budget or agreement;
7. and link to implementation evidence if funded work later begins.

For example:

```text

        ↓

        ↓
accepted agreement
        ↓

        ↓
approved scope
        ↓
implementation evidence
```

Each stage should remain separately traceable.
